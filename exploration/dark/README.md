# Control — public preview

Dark visual system, Logo B, Romanian only in this iteration. The page is a control surface: a private person monitors and commands real processes. HVAC automation and BMS are the craft. The board is a simulation of heating, ventilation and a pump.

**Open.** `index.html`. Identity sheet: `identity.html`.

```bash
python3 -m http.server 8000
# http://127.0.0.1:8000/exploration/dark/
node exploration/tools/check.mjs dark/index.html dark/identity.html
```
