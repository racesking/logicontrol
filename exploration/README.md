# Identity exploration (Stage A)
Static, noindex preview of three Logicontrol identity concepts for owner review. Not the production site; no concept is selected.

| Path | Concept |
|---|---|
| [index.html](index.html) | Comparison gallery (start here) |
| [light/](light/) | Signal — light, architectural |
| [dark/](dark/) | Control — dark, building-control interface |
| [mixed/](mixed/) | Current — editorial light with immersive dark sections |
| screenshots/ | 360/768/1440px captures generated by the check tool |
| tools/check.mjs | Dependency-free browser check (Node 22 + Chrome) |

## Preview locally
From the repository root:

```bash
python3 -m http.server 8000
# open http://localhost:8000/exploration/
```

To reproduce the GitHub Pages project path (`/logicontrol/`):

```bash
mkdir -p /tmp/lc-site && ln -sfn "$PWD" /tmp/lc-site/logicontrol
python3 -m http.server 8000 -d /tmp/lc-site
# open http://localhost:8000/logicontrol/exploration/
```

## Check
```bash
node exploration/tools/check.mjs            # all pages at 360/768/1440px
node exploration/tools/check.mjs --shots    # also refresh screenshots/
```
The script serves the repository under `/logicontrol/` and reports horizontal overflow, console errors, failed requests, root-absolute URLs, missing noindex, broken internal links and focus stops without a visible indicator. It does not replace manual review of contrast, screen-reader output or design quality.
